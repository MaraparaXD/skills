# Skills do Claude Code

Coleção de skills e plugins que uso no Claude Code.

## Instalação

Como marketplace de plugins (animation-components, authoring-motion, core-3d-animation, extended-3d-scroll, meta-skills):

```
/plugin marketplace add MaraparaXD/skills
/plugin install core-3d-animation@local-design-skillstack
```

Skills avulsas (as outras pastas): copie a pasta para `~/.claude/skills/`.

## Licenças

Várias skills vêm de terceiros e mantêm a licença original declarada no `SKILL.md`
(ex.: GSAP e Vercel em MIT, impeccable em Apache 2.0).
