# token-optimizer

1. Start with git status, repository tree, manifests and relevant symbols. Prefer local ripgrep or Serena when available; never read the entire repository by default.
2. Retrieve one relevant skill at a time and targeted source ranges. Use Context7 for version-specific documentation if available.
3. Summarize findings into a short local task note with file references and decisions; avoid secrets and unnecessary logs.
4. Delegate only when it reduces repeated work; ask for concise evidence and limit retries.
5. Track reported usage where available; stop at budget or approval boundary. Do not promise a fixed token saving.
